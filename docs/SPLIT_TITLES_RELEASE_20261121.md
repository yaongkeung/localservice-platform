# 화면 제목과 검색 제목 분리 — 2026-11-21

## 문제와 보완

사용자는 네이버에 노출된 JS유리 페이지처럼 짧은 화면 제목과 설명을 붙인 검색 제목을 요구했다. 앞선 개선은 검색어 나열과 길이를 줄였지만 H1과 title을 분리하지 못했다. 연남동 페이지의 실제 HTML을 읽어 H1 `연남동 유리문`, title `연남동 유리문 | 실내 구획·출입 동선을 고려한 상담`을 확인했다.

`pageTitles`를 공통 표시 규칙으로 추가했다. H1은 읍·면·동+대표 업무, title/OG는 전체 지역명+대표 업무 ` | `와 제공된 설명·관련 업무로 만든다. 등록된 지역·업종을 사용해 두 입력값이 비어 있던 기존113김포 글도 처리한다. 별도 seo_title과 새 형식에서 직접 수정한 검색 설명은 보존한다. 자동 작성은 처음부터 구분된 검색 제목을 생성하며 관리 화면에 화면 제목과 검색용 제목을 별도로 표시한다. 기존 DB 제목·본문·작성 이력·사진·발행일·대표 URL은 이번 표시 개선으로 갱신하지 않는다.

기존 편집 클라이언트가 입력 원문 `강화유리 유리집`과 정리된 자동 제목 `강화유리 …`의 접두부를 비교해 사진별 설명을 다시 열 때 초기화할 수 있었던 문제도 함께 고쳤다. 접두부를 같은 대표 업무 규칙으로 계산하고, 저장된 copy가 있는데 제목만 기본 주제로 남은 경우 그 실제 설명을 사용한다. 새 작업 정보를 만들어내지 않는다.

Article.headline은 실제 H1, Article.name과 OG는 검색 제목으로 맞춘다. 공개 감사에도 같은 업무의 제목·H1·구조화 정보가 맞는지 검사한다. 검색용 title의 최종 채택 여부는 네이버가 결정한다. 화면 제목을 줄였다는 사실만으로 미색인의 확정 원인이 해결됐다고 판단하지 않는다.
