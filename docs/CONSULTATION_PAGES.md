# 업체 상담 페이지 운영

1. 업체를 등록하고 상담 번호·서비스 지역·네이버플레이스 정보를 확인합니다. 이 정보는 같은 업체의 페이지에 함께 사용합니다.
2. 사진으로 작성에서 업체, 작업 지역, 제목에 쓸 지역명과 대표 업무를 입력합니다. 상담 번호는 확인된 업체 번호가 자동으로 들어가며 페이지별로 바꿀 수 있습니다.
3. 사진을 첨부하고 사진으로 포스팅 자동 완성을 누릅니다. 기본 정보 저장·사진 등록·관찰·본문 집필을 한 흐름으로 처리합니다.
4. 상단 전화 안내, 세부 업무, 지역 소개, 사진과 설명, FAQ, 진행 순서와 플레이스를 확인하고 발행하면 메인에 바로 표시됩니다. 자동 생성만으로 공개하지 않습니다.

기존 공개 글은 영구 주소와 본문/사진을 보존한 채 새로운 상담 화면으로 표시합니다. 사진이 어떤 지역의 어떤 시공 결과인지 확인되지 않았다면 업체 제공 사진으로 안내합니다. 실제 작업 메모가 있으면 접힌 본문 수정에서 사진 사이에 추가할 수 있습니다.

## 실제 후기

업체 수정 → 고객 후기 등록(선택)을 펼쳐 원문을 빈 줄로 구분합니다. 원문과 출처, 게시 가능 여부를 확인해야 저장할 수 있습니다. 최대 6개이며 출처 링크는 선택입니다. 확인된 후기만 표시하고 후기가 없으면 영역을 생략합니다. 허위 후기나 별점, 고객 이름과 날짜는 자동 작성하지 않습니다.

## 50~300페이지 제공 시

업체/전화/플레이스와 일반적인 상담 절차는 공통 정보입니다. 각 페이지의 고유 내용은 해당 사진의 관찰, 업무의 세부 조건과 상담 준비, 실제 제공된 작업 메모입니다. 지역명이나 동의어만 바꾸어 다른 글로 취급하지 않습니다. 같은 업체의 지역명/키워드를 제외한 본문에서 12자 조각의 Jaccard 유사도가 0.82 이상이면 발행 전에 보강을 요청합니다. 내부 기준이며 네이버의 판정 기준이 아닙니다. 기존 동일 제목/본문 해시 검사는 유지하고, 같은 사진의 다른 글 재사용은 허용합니다.

입력 자료가 같으면 의미 있게 다른 콘텐츠를 50~300개 보장할 수 없습니다. 다른 사진·실제 업무 정보가 필요합니다. 현재 자동 작성 한도는 글당 하루 3회, 전체 하루 10시도이며 한 시도는 사진 관찰과 본문 집필의 최대 두 번 추론입니다. 실패도 시도에 포함하며 기존 원문과 사진을 보존합니다. 300페이지 동시 생성이나 운영 부하를 검증한 것은 아닙니다.

## 검색 기준

[네이버 콘텐츠 작성 권장 사항](https://searchadvisor.naver.com/guide/content-basic)에 맞춰 실제 사진과 유용한 고유 정보를 중심으로 구성합니다. 전화 이미지는 실제 번호를 넣는 SVG이며 전화 링크와 본문은 HTML로도 제공합니다. 지역 소개는 확인된 공식 출처만 사용합니다. 페이지 수, 글자 수, 유사도 검사를 실제 네이버 검색 노출이나 고객 확인으로 계산하지 않습니다.

## 진행 표시와 공개 버튼

요청을 누르면 화면 하단의 고정 안내가 작업 단계·회전 표시·경과 시간을 표시합니다. 완료/오류 후에도 안내가 남으며 닫을 수 있습니다. 서버 응답을 받기 전에는 완료로 표시하지 않습니다. 저장 응답을 확인하지 못하면 저장된 글 확인 링크로 결과를 확인한 뒤 다시 시도합니다.

관리자는 사진/내용을 확인한 뒤 ‘확인하고 발행’을 누릅니다. 저장과 DRAFT→PUBLISHED를 원자적으로 처리하며 실패하면 해당 요청의 변경을 되돌리고 오류를 표시합니다. 계약 설정·잔여 수량·검수 요청·승인 단계를 요구하지 않습니다. 기존 계약/배정/감사 기록은 보존합니다. 시험용 글/업체는 발행해도 메인에서 제외됩니다.
