# 지도와 게시판

메인은 검색 → 서울 지도 → 게시판형 최신 글 → 업종 순서입니다. 게시판은 서버 HTML로 제목·업종·지역·업체·등록일을 제공합니다. 모바일에서는 행을 세로로 정리합니다. 현재 없는 조회·댓글 수와 사진을 꾸며 넣지 않습니다.

## 경계 출처와 한계

- 저작권자: 서울특별시. 제공기관: 서울신용보증재단.
- 데이터: [서울시 상권분석서비스(영역-행정동)](https://data.seoul.go.kr/dataList/OA-22160/S/1/datasetView.do), OA-22160.
- 이용 조건: 공공누리 제1유형 (출처표시, 상업적 이용 및 변경 가능).
- 원본 파일 표시 수정일: **2023-10-31**. 다운로드 확인일: 2026-11-13. 페이지의 데이터 갱신일과 첨부 파일 수정일은 다릅니다. 현재 행정구역과 차이가 있을 수 있습니다.
- 원본: SHP/DBF, UTF-8, EPSG:5181. 425개 행정동. 행정동 코드 앞 5자리로 묶어 25개 구 경계를 합집합 처리했습니다.
- 가공: SVG 좌표로 변환하고 연속 꼭짓점 간 거리가 20m 미만인 점은 생략했습니다. 법적 경계 확인이나 측량용이 아닌 UI 탐색용입니다. 동 경계를 합쳐 만든 구 외곽으로, 별도 공식 구 경계 파일이 아닙니다.
- 화면에 출처·이용 조건·원본 날짜·가공 사실을 표시합니다. 데이터를 갱신할 때 같은 항목을 함께 변경해야 합니다.
- `src/boundaries.js`는 가공된 표시용 SVG 경로입니다. `center`는 EPSG:5181 → WGS84로 변환한 각 구 경계 bounding box 중심이며 실제 지리 중심점은 아닙니다.

## 동작

- 구 호버/클릭: 구 강조, 오른쪽 동 지도 표시. 마우스 이동만으로 페이지를 이동하거나 글 필터를 확정하지 않습니다.
- 동 호버: 살짝 커지는 효과와 색상 강조. 클릭/터치 또는 선택란: 동 선택 확정.
- ‘지역 글 보기’: `district`/`dong` 조건으로 실제 샘플 글을 조회합니다. 지역의 `admin_code`로 연결하며, 동 코드가 등록되지 않은 글을 임의의 동에 배정하지 않습니다.
- 게시물 없는 지역은 검색 결과만 비어 있으며 빈 지역×업종 게시판을 대량 생성하지 않습니다.
- 키보드 Tab/Enter/Space와 선택란을 제공합니다. 움직임 줄이기 설정에서는 애니메이션을 끕니다.
- 경계 자료를 불러오지 못하거나 JavaScript를 끈 경우에도 기존 지역 검색과 링크는 이용할 수 있습니다.

## 네이버 지도 연결

네이버 배경지도와 서울시 경계 기반 SVG 대체 지도를 함께 제공합니다. 런타임 환경 변수 `NAVER_MAP_CLIENT_ID`가 있으면 지도 영역이 화면 가까이 왔을 때 공식 SDK를 로드합니다. 값이 없으면 외부 지도 요청 없이 SVG를 유지합니다. ID는 소스에 저장하지 않으며 Client Secret은 사용하지 않습니다. 브라우저용 ID는 SDK 요청 시 브라우저에 공개되므로 네이버 콘솔의 Web 서비스 URL 제한을 적용해야 합니다.

구/동 경계는 `src/naver-geometry.js`의 WGS84 GeoJSON으로 제공합니다. EPSG:5181 원본에서 20m 미만 연속 점을 생략하고 6자리 소수 좌표로 변환했습니다. 지리 경계를 임의 확대하지 않고 호버 시 색/선 굵기로 강조하며, 클릭 시 경계에 맞춰 확대합니다. 오른쪽 SVG 동 지도에는 기존의 미세 확대 효과를 유지합니다. 구 전체/동 선택, ‘서울 전체 보기’, 화면 크기 변경을 지원합니다.

SDK 인증 실패·네트워크 실패·12초 로딩 시간 초과 시 안내와 함께 SVG 지도로 복귀합니다. 원본 경계 로딩과 게시글 필터는 네이버 인증과 별도로 작동합니다. 네이버 로고와 지도 데이터 출처는 SDK 기본 표시를 유지합니다.

### 설정과 검증 상태

1. 로컬: `.dev.vars.example`을 `.dev.vars`로 복사하고 Client ID를 설정합니다. `npm run dev`에서만 읽으며 Git에서 제외합니다.
2. Cloudflare: 배포 시 같은 이름의 런타임 변수를 등록합니다. 이 작업에서는 Cloudflare 설정/배포를 수행하지 않았습니다.
3. 네이버 Maps Application의 Dynamic Map 및 Web 서비스 URL을 확인합니다. 운영 주소 `https://gongsa8282.xyz`, 로컬 확인용 `http://localhost`를 각각 등록해야 합니다.
4. 현재 로컬에서는 네이버의 `navermap_authFailure` 응답을 확인했습니다. 등록 주소를 확인한 뒤 실제 배경지도와 경계 클릭을 재검증해야 합니다. 인증 실패 시 SVG 복귀 및 선택 기능은 브라우저에서 확인했습니다. 실제 도메인 검증은 배포 후 필요합니다.

참고: [네이버 데이터 레이어 가이드](https://navermaps.github.io/maps.js.ncp/docs/tutorial-2-DataLayer.html).
