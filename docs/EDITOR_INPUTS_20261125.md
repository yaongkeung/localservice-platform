# 제목 지역명과 긴 업무 문구 입력 개선

2026년 11월 25일 운영 사이트에 반영했습니다. 지역 선택 후 자동 입력은 유지하면서 제목용 지역명은 자유롭게 수정할 수 있고, 업무 키워드 문구 전체를 제목과 본문 작성에 전달합니다.

## 변경 내용

- 제목 지역명의 행정구역 문자열 일치 검사를 저장·자동 작성 단계에서 제거했습니다. 선택한 실제 행정구역은 region_id로 검증·보관하며, 제목용 문자열은 별도로 유지합니다.
- 저장할 때 읍·면·동 이름을 다시 전체 지역명으로 바꾸던 처리와 수정 화면 진입 시의 같은 처리를 제거했습니다. 지역 선택을 바꿀 때는 자동 입력하고, 이후 직접 수정한 값은 그대로 저장합니다.
- 대표 업무 입력을 40자에서 80자로, 저장 제목을 120자에서 200자로 늘렸습니다. 제목·H1·상단 안내·자동 본문 작성 입력에서 첫 업무만 추출하던 처리를 제거했습니다. 업종 분류의 내부 대표 작업 식별은 유지합니다.
- 검색용 제목이 있는 화면을 다시 열기만 했을 때 문구를 초기화하지 않습니다. 입력을 실제로 바꾸면 새 입력을 반영합니다.
- 신규 영구 주소의 작업 지역은 사용자가 임의로 줄인 표시명이 아닌 선택한 행정구역에서 가져옵니다. 기존 영구 주소는 바꾸지 않습니다.
- 관리자 상단의 `포털 보기`를 집 아이콘이 있는 `홈으로 가기`로 바꿨습니다. 18px/800 굵기와 충분한 클릭 영역을 적용했습니다.
