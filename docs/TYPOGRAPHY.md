# 글씨체와 화면 밀도

2026-11-18 사용자의 요청에 따라 Apple 한국 사이트를 직접 비교하고 기존 포털의 글씨·테두리·버튼을 조정했습니다. 게시판·등록 업체·업종 사진·업체/지역 선택·포스팅 순서와 전화 CTA 배치는 유지합니다.

Apple 한국 페이지의 제목600/설명400 굵기와 간결한 계층, 여백과 둥근 버튼을 참고했습니다. 제품 홍보용 큰 제목 크기를 정보 포털에 그대로 적용하지 않고 목록/본문 밀도에 맞춥니다. Apple의 타이포그래피 안내도 읽기 쉬운 크기·굵기·상대적인 계층과 실제 화면 검증을 강조합니다. 네이티브 앱의 pt 권장값을 웹 px 기준으로 간주하지 않습니다.

| 용도 | PC | 모바일 |
| --- | --- | --- |
| 기본 UI | 16px | 16px |
| 게시판 글 제목 | 16px / 500 | 16px / 500 |
| 포스팅 본문 | 17px / 400 | 16px / 400 |
| 포스팅 상세 제목 | 최대30px / 600 | 23px / 600 |
| 본문 소제목 | 25px / 600 | 22px / 600 |
| 주요 탐색·업종 링크 | 15px | 14~15px |
| 보조 정보 | 13~14px | 13~14px |
| 주요 전화번호 | 24px / 650 | 23~24px / 650 |

본문 줄 간격은 주로1.75~1.8, 카드/메뉴는1.5~1.65입니다. 버튼과 선택창의44px 접촉 영역을 유지합니다. 전화번호는 붉은 강조와 모바일 고정 버튼을 유지합니다. 음영·테두리의 대비를 낮추되 본문은 어두운 색을 유지합니다. 로고의 원본 벡터와 빨간 핀은 바꾸지 않습니다.

Pretendard1.3.9 가변 글꼴은 공식 패키지에서 내려받아 파일 무결성을 확인하고 사이트 내부에서 제공합니다. 원본 파일을 변형하지 않았으며 [SIL OFL1.1 원문](../public/media/pretendard-ofl.txt)을 함께 배포합니다. WOFF2 파일은2,057,688바이트이며 `font-display:swap`과 시스템 대체 글꼴을 사용합니다. 버전이 들어간 자산 이름과1년 immutable 캐시를 적용합니다. 외부 글꼴 서버를 호출하지 않고 CSP는 자체 글꼴만 허용합니다. 이미지/허가문/글꼴 외의 임의 파일은 공개하지 않습니다.

글씨와 표면의 최종 조정은 `src/soft-ui.js`에 모아 기존 구조 규칙 뒤에 적용합니다. 데이터·자동 작성 내용·지역/업종·대표 URL·검색 메타·DB는 변경하지 않습니다.

참고: [Apple 한국](https://www.apple.com/kr/), [Apple Typography](https://developer.apple.com/design/human-interface-guidelines/typography), [Pretendard 공식 배포](https://github.com/orioncactus/pretendard).
