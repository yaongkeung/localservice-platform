# 동네핀 브랜드

- 이름: 동네핀
- 문구: 우리 동네 전문가를 콕.
- 심벌: 사용자가 제시한 위치 마커를 참고해 새로 작성한 가는 빨간 위치 핀 SVG. 흰 원 안에 소문자 p 윤곽을 표시합니다.
- 글자: 짙은 먹색 `#40383b`과 빨간색 `#d83d36`의 조합. Gmarket Sans Bold의 ‘동네핀’ 세 글자 윤곽을 벡터 그래픽으로 사용합니다.

서체는 [G마켓 공식 배포처](https://corp.gmarket.com/fonts/)에서 받은 Gmarket Sans TTF Bold입니다. 공식 안내에 SIL Open Font License에 따른 이용 범위가 명시되어 있습니다. 폰트 파일을 사이트나 저장소에 배포하지 않고, 세 글자로 만든 로고 그래픽만 사용합니다. 외부 폰트 요청 없이 모바일과 PC에서 동일하게 표시합니다.

`src/brand.js`가 심벌·접근성 이름·안내 문구를, `src/brand-wordmark.js`가 글자 그래픽을 제공합니다. 두 SVG는 장식으로 처리하고 링크의 접근성 이름에 ‘동네핀’을 표시합니다. 공개/관리 화면에 같은 로고를 사용하며 본문 글꼴은 유지합니다.

## 상담 페이지 전화 안내 (2026-11-17)

상단 배경은 아이보리와 옅은 세이지, 제목은 짙은 녹색 계열로 표시합니다. 전화 안내 이미지는 빨간 p 핀을 넣은 흰 말풍선 모양이며, 번호는 코랄색 글씨로 직접 표시합니다. 전화 버튼은 흰 전화 아이콘과 번호, 이동 화살표를 넣은 비대칭 둥근 코랄색 버튼입니다. 중간 상담 영역과 모바일 고정 버튼도 같은 팔레트로 맞춥니다. 번호는 실제 저장된 값을 사용하고 이미지와 HTML 전화 링크를 함께 표시합니다.
