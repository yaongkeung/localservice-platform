# 지역 이름과 코드

현재 메인은 지도 없는 게시판 포털입니다. 네이버 SDK·지도 API·경계 좌표·SVG·지도 설정 응답을 제거했습니다. 기존 지도의 지역 목록은 이름과 코드만 추출하여 전국 시·도 → 시·군·구 → 읍·면·동 선택란에 사용합니다. 지도 키와 외부 패키지는 실행에 필요하지 않습니다.

## 출처

본 데이터는 통계청 통계지리정보서비스(SGIS, https://sgis.kostat.go.kr)에서 공공누리 제1유형으로 개방한 행정동 경계를 가공한 것이며(가공: vuski/admdongkor, https://github.com/vuski/admdongkor), CC BY 4.0으로 배포됩니다. 이 프로젝트에서는 **이름과 코드만 추출**했으며 기하 정보를 배포하지 않습니다.

- [원본 고정 버전](https://github.com/vuski/admdongkor/tree/d5d5a821c8de6cc337d47eeca604d7af76271c9b/ver20261001): `HangJeongDong_ver20261001.geojson`
- 기준일 2026-10-01, 커밋 `d5d5a821c8de6cc337d47eeca604d7af76271c9b`.
- 원자료 편제 기준 시도 16, 시군구 경계 단위 256, 읍면동 3,559개. 일반시의 비자치구도 별도 선택 단위입니다. 현행 행정구역의 법적 판단용이 아닙니다.
- 원자료 공공누리 제1유형, 가공물 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). 원본 라이선스를 `REGION_DATA_LICENSE.txt`에 보존합니다.
- 원자료 `sido`, `sgg`, `adm_cd2`를 사용하며 통계청 코드 `adm_cd`와 섞지 않습니다. 읍면동 코드는 행정기관코드 앞 8자리를 사용합니다.

## 갱신

외부 의존성 없이 `node scripts/build-regions.mjs <원본.geojson>`으로 `src/regions-data.js`를 생성합니다. 자료를 갱신할 때 스크립트의 기준일/커밋, 이 문서와 라이선스도 함께 확인합니다.

`/assets/regions.json`은 시도와 시군구 목록, `/assets/regions/{시군구코드}.json`은 해당 읍면동 이름과 코드만 반환합니다. 전국 좌표나 이미지 파일을 내려받지 않습니다.

## 선택 동작

- JavaScript가 있으면 시도 선택 시 시군구, 시군구 선택 시 읍면동 목록을 채웁니다. ‘지역 적용’을 눌러 검색 결과를 확정합니다.
- JavaScript/목록 요청을 사용할 수 없으면 ‘지역 적용’으로 서버 화면을 갱신한 뒤 하위 지역을 이어서 선택할 수 있습니다. 선택된 지역의 목록은 서버 HTML에도 포함됩니다.
- 늦게 도착한 이전 목록 응답은 새 선택을 덮어쓰지 않습니다. 지역 변경 시 이전 하위 지역 값을 지웁니다.
- 지역·업종·글 종류·키워드 조건을 함께 적용할 수 있습니다. 검색/글 종류/업종 이동 시 현재 필터를 유지하고, ‘필터 초기화’로 해제합니다.
- 샘플 글에 읍면동 코드가 없으면 임의의 동에 배정하지 않습니다. 글 없는 지역은 빈 검색 결과로 표시하며 빈 지역×업종 게시판을 생성하지 않습니다.
