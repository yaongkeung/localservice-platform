# 샘플 사진과 표시 규칙

현재 3장의 사진은 AI 생성 샘플이며 실제 업체 작업 실적이 아닙니다. 메인 카드에는 샘플 배지, 게시판에는 샘플 안내, 상세 페이지에는 AI 생성 이미지 설명을 표시합니다. 실제 사진이 등록되면 이 샘플을 교체해야 합니다.

| 업종 | 게시글 | 커버 | 썸네일 |
| --- | --- | --- | --- |
| 배관·누수 | 101 | `/media/plumbing-cover.jpg` | `/media/plumbing-thumb.jpg` |
| 전기·조명 | 102 | `/media/electrical-cover.jpg` | `/media/electrical-thumb.jpg` |
| 에어컨·청소 | 103 | `/media/cleaning-cover.jpg` | `/media/cleaning-thumb.jpg` |

- `src/photos.js`의 `postImages`는 SCHEMA의 post_images 관계를 따릅니다. `post_id`, `storage_key`, `alt_text`, `sort_order`를 기준으로 연결하며 로컬 썸네일 키와 샘플 여부를 추가로 보관합니다. DB 스키마를 변경한 작업은 아닙니다.
- 게시글 대표 사진은 해당 글 사진의 `sort_order`, `id` 순서에서 첫 장입니다. 사진 없는 글은 카메라 모양을 표시하며 다른 글의 사진을 임의로 배정하지 않습니다.
- ‘오늘의 업종 한 컷’은 Asia/Seoul 날짜 기준으로 공개된 글의 사진에서 업종별 한 장을 고릅니다. 같은 날짜에는 같은 선택을 유지하고, 여러 후보가 있으면 날짜에 따라 순환합니다. 비공개 글·미래 게시글·사진 없는 글은 제외합니다. 매일 새 AI 사진을 생성하거나 외부 유료 API를 호출하는 기능이 아닙니다.
- 커버는 JPEG 960×640, 썸네일은 180×120으로 최적화했습니다. 너비/높이, 대체 텍스트, 지연 로딩, 반응형 이미지 후보를 제공합니다.
- `wrangler.jsonc`의 `public`/`ASSETS` 설정이 이미지 제공에 필요합니다. 로컬은 `scripts/local-media.mjs`를 사용하며, JPEG 파일명 경로만 허용합니다. CSP는 같은 출처 이미지만 허용합니다.
- 게시글/업체 프로필/지역·업종 게시판도 같은 사진을 참조합니다. 사진과 제목 링크 모두 숫자 ID 게시글 URL로 이동합니다.

생성 방법: 내장 ImageGen. 배관 연결 점검, 분리한 LED 조명 커버 점검, 분리한 에어컨 필터 청소의 세 가지 별도 프롬프트를 사용했습니다. 인물 얼굴·문구·브랜드·워터마크를 제외하고 밝은 주거 공간의 편집 사진 느낌으로 생성했습니다.
