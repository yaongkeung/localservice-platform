## 확인된 문제와 원인 판단

**집계 지연:** 페이지 집계는 11월 16일 자료이지만 개별 검사는 오늘 홈페이지·김포 글, 11월 24일 청천동·화곡동 수집도 확인합니다. Google의 [페이지 보고서 설명](https://support.google.com/webmasters/answer/7440203?hl=ko)은 특정 주소의 상태를 URL 검사로 확인하도록 안내합니다.

**미발견 18개:** Google이 아직 보지 못한 URL로 보고됩니다. 현재 링크와 사이트맵에는 들어 있지만 발견·수집 일정과 보고 처리에 차이가 있습니다. 정상 처리된 TXT 61개와 RSS 21개가 있어 XML 실패 하나로 모든 미색인을 설명할 수 없습니다. Google은 [사이트맵 오류 사유](https://support.google.com/webmasters/answer/7451001?hl=en)로 접근 제한·잘못된 주소 외에 낮은 수집 수요도 설명합니다. 동네핀의 정확한 내부 선택 사유는 공개되지 않았습니다.

**수집 후 미색인 2개:** 삼산동과 원당동은 가져오기와 색인 허용이 성공했는데 검색 대상으로 선택되지 않았습니다. 삼산동은 11월 24일 20:29, 원당동은 11월 20일 05:50의 수집 기록입니다. 현재 응답이 정상이라는 이유로 해결됐다고 판단할 수 없습니다. [URL 검사 설명](https://support.google.com/webmasters/answer/9012289?hl=en)은 실시간 검사가 실제 색인이나 대표주소 선택을 보장하지 않는다고 명시합니다.

콘텐츠 측면에서 삼산동 글은 여러 분배기 사진이 같은 현장인지, 실제 증상과 조치가 무엇인지 확인되지 않아 관찰·상담 준비 중심입니다. 원당동 옥상누수 글도 배관 주변 물·거품·녹 사진 설명 비중이 높습니다. 실제 증상을 구분하는 방법과 가능한 작업 범위를 더 구체적으로 연결할 수 있습니다. 이는 개선 후보이며 Google이 밝힌 확정 미색인 사유는 아닙니다. 사실이 없는 시공 결과·가격·완료 날짜를 만들어 채워서는 안 됩니다.

공개 주소 90개는 글 25개, 지역목록 49개, 업종목록 8개, 업체 6개, 홈·소개 2개입니다. 여러 지역 단계가 같은 1~2개 글을 반복해 보여주는 목록의 독립적인 검색 가치를 검토할 수 있습니다. 이 비율 자체는 Google 위반 기준이 아닙니다. 기존 주요 링크와 대표주소를 유지하면서 독립적인 정보가 약한 목록부터 판단해야 합니다.

## 공식 최근 공지와 비교

- [11월 11일 CDN 안내](https://developers.google.com/search/blog/2026/11/crawling-cdn?hl=en)는 방화벽·CAPTCHA가 Googlebot을 막을 수 있다고 설명합니다. 현재 Google 자체 실시간 검사와 호스트 통계에서는 전체 차단 양상이 확인되지 않았습니다. 일반 요청의 UA 이름을 바꾸는 검사는 인증된 실제 Googlebot IP 로그의 대체가 아닙니다.
- [11월 16일 Search Analytics API 업데이트](https://developers.google.com/search/blog/2026/11/search-analytics-api-update)는 검색어·멀티모달·국가·기기 보고 필터에 관한 공지입니다. 색인 0을 설명하는 장애 공지는 아닙니다.
- [11월 코어 업데이트](https://status.search.google.com/incidents/WLxcJyC6jMWMfryxsKMc)는 한국시간 11월 24일 23:03에 완료됐습니다. 순위 변화 공지를 이 사이트의 미색인 원인으로 확정할 수 없습니다. 11월 24일의 12월 업데이트 공지는 12월 실행을 예고한 것입니다.
- [Search Console 데이터 이상 공지](https://support.google.com/webmasters/answer/6211453?hl=en)에는 현재 페이지 색인 보고서의 최근 장애가 공지돼 있지 않습니다. 11월 9~11일 생성형 AI 노출 기록 문제는 페이지 집계 정지와 별개입니다. 이 속성의 지연을 Google 전체 장애로 단정하지 않습니다.
- [10월 1일 갱신 AI 콘텐츠 가이드](https://developers.google.com/search/docs/fundamentals/using-gen-ai-content)는 정확성·관련성·사실 확인과 추가 가치의 중요성을 설명합니다. 단어만 다르게 하거나 같은 사진에 상호·번호를 붙이는 것으로 실제 작업 정보가 추가되지는 않습니다.

## 공개 응답과 과거 오류

현재 XML은 HTTP 200, application/xml, 11,219바이트입니다. 정식 XML 파싱·namespace·90개 URL·TXT와 같은 목록을 확인했습니다. 공개 주소 90개·리소스 165개·추가 연결 5개 검사에서도 오류가 없었습니다. 이 검사는 기본 접근·대표주소·메타·리소스에 관한 것이며 검색 품질이나 순위 승인은 아닙니다.

과거 404는 크롤링 48회로 집계되며 예시 46행의 고유 주소는 40개입니다. 그중 38개는 글이 없는 업종목록으로 현재도 404이고, 강화도어 목록과 favicon.ico는 현재 200입니다. 현재 사이트맵과 연결 검사에서는 빈 목록으로 유도하는 깨진 링크가 발견되지 않았습니다. 과거 기록을 현재 공개 글 40개의 오류로 해석하지 않습니다.

홈페이지에 실제로 연결된 192px PNG와 ICO는 현재 200이며 차단·noindex 헤더가 없습니다. 과거 ICO의 404 기록이 현재 파비콘 파일 부재나 전체 게시글 미색인을 뜻하지는 않습니다. [Google 아이콘 기준](https://developers.google.com/search/docs/appearance/favicon-in-search)을 충족해도 검색결과 표시는 보장되지 않습니다.

2. 수집 후 미색인 2개 글부터 확보된 실제 증상·검사 대상·자재·확인 방법·작업 범위·조치·결과를 보완합니다. 확인할 사실이 없는 사진은 참고자료로 구분하고, 실질적인 차이가 없는 안내글은 통합 여부를 검토합니다.
3. 글의 차이를 제목 끝 단어로만 만들지 않고 지역·사진·실제 업무의 관련성을 확인합니다. 독립 정보가 빈약한 목록도 함께 점검합니다.
