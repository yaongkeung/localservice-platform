# 동네핀 색인 개선 반영 — 2026년 11월 25일

검색엔진이 이전 글을 찾는 경로와 중복 목록의 대표 주소를 보완하고, 앞으로 작성할 글의 사실 확인 기준을 강화했습니다. 변경 전 Google 진단에서 확인한 실제 색인 상태와 이번 수정의 효과를 구분합니다. 이번 배포만으로 네이버·구글의 색인 완료나 검색 순위를 확인한 것은 아닙니다.

## 운영 반영 내용

| 구분 | 변경 사항 |
|---|---|
| 메인 목록의 2페이지 이후 | 기존에는 모든 검색 매개변수를 noindex로 처리하고 홈페이지를 대표 주소로 지정했습니다. 이제 필터 없는 `/?page=2`는 자기 대표 주소·별도 제목·설명을 가지며 색인을 허용합니다. 이전·다음 링크와 XML/TXT 사이트맵에서 이어집니다. |
| 잘못된 페이지 번호 | 1페이지·0·문자·중복 매개변수·범위를 벗어난 번호를 실제 존재하는 목록 주소로 한 번 정규화합니다. |
| 지역·업종 중복 목록 | 같은 종류의 목록에서 공개 게시글 ID 집합이 완전히 같은 경우만 가장 구체적인 게시판으로 대표 주소를 통일합니다. 19개 중복 목록은 계속 열리며 대표 게시판 링크를 제공합니다. 게시글 자체는 변경하지 않습니다. |
| 사이트맵 | 90개 주소에서 72개 대표 주소로 정리했습니다. 공개 게시글 25개는 전부 유지하고, 중복 목록 19개를 제외하고 메인 목록 2페이지 1개를 추가했습니다. XML/TXT의 주소와 순서가 일치합니다. |
| 관련 글 | 같은 업체·업종·지역의 관련도와 발행일을 기준으로 최근 공개 글을 연결합니다. 기존 첫 세 글만 반복해서 연결하던 방식을 보완했습니다. |
| 앞으로의 자동 작성 | 업무별 판단 항목, 실제로 관찰한 사진 수, 선택 작업 메모 유무, 확인되지 않은 사실의 범위를 작성 입력에 추가했습니다. 색상·물체 나열에 그치지 않고 요청 업무의 선택 조건과 추가 확인 정보를 연결하도록 수정했습니다. |

검색어·지역·업종 필터 목록의 noindex는 유지합니다. 단일 글만 있다는 이유로 모든 지역 게시판을 제외하지 않습니다. 기존 글의 대표 주소·숫자 주소의 301 연결·사진·발행일과 관리 권한을 보존합니다. 기본 메인 목록은 여전히 20개이며 전체 화면 구조를 바꾸지 않았습니다.

## 기존 문구의 사실 확인

공릉동 #143은 작업 메모가 없는데도 요약과 도입에 “노원구에서 진행 중인 유리 작업 현장”이라고 작성되어 있었습니다. 원문과 사진 연결을 백업·복원 검증하고 수정 전 상태를 작성 기록에 보관한 뒤, 두 부분을 업체 제공 사진을 참고한 상담 안내로 고쳤습니다. 촬영 지역이나 실제 시공 결과를 새로 만들지 않았습니다. 제목·주소·사진·발행일은 그대로입니다.

다른 기존 글을 일괄 재작성하거나 사례를 만들어 채우지 않았습니다. 새 자동 작성 기준은 이후 작성·재작성에 적용됩니다. 실제 작업의 요청·조치·결과가 있다면 선택 작업 메모에 기록해야 해당 근거를 활용할 수 있습니다. 메모는 필수가 아니며 원문은 공개하지 않습니다.

## Google 제출 상태와 남은 사항

운영 반영 후 XML/TXT 사이트맵을 각각 한 번 재제출하고 접수 완료를 확인했습니다. TXT의 기존 성공 상태는 유지되지만 마지막 읽기 날짜는 11월 22일·발견 61로 아직 갱신 전입니다. XML은 제출일이 11월 25일로 바뀌었으나 “가져올 수 없음·발견 0” 표시가 남아 있습니다. XML의 현재 HTTP 접근·문법 검증과 Google의 사이트맵 처리 성공은 별개이며, 이 문제를 해결 완료로 기록하지 않습니다.

이번 변경은 수집 경로와 대표 주소 신호를 개선한 것입니다. Google의 25개 글에 대한 실제 색인 재판단과 네이버의 수집·색인 반영은 추가 확인이 필요합니다. 기술 점검 통과를 노출 보장이나 패널티 해제로 설명하지 않습니다.
