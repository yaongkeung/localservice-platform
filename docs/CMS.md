## 지역명·자동 연관 키워드 (2026-11-18)

전국 지역을 선택하면 제목 지역명에 시·군·구와 읍·면·동을 함께 채웁니다. 서울은 `서울시 종로구 사직동`, 경기 시 지역은 `용인시 처인구 마평동`, 도의 군 지역은 `전남 강진군 마량면`처럼 표시합니다. 세종은 `세종시 연기면`으로 중복 시 이름을 합칩니다. 광주 구 지역은 `광주 광산구 운남동`으로 표시합니다. 강원·제주는 짧은 도 이름을 유지하고 경기도와 통합/광역/자치 등 긴 명칭은 제목에서 제거합니다. 번호로 나뉜 동의 기존 묶음 규칙은 유지합니다.

사용자는 대표 업무와 사진을 입력합니다. ‘자동 연관 키워드’는 읽기 전용이며 사진 분석 후 업체 업무/대상에 맞게 채워집니다. 제목은 지역명+대표 업무+자동 연관 키워드+사진에 맞춘 뒷문장입니다. 사진 분석 전에는 지역명+대표 업무만 미리 보여주며 기존 공통 뒷문장을 붙이지 않습니다.

상단 문구·업무 카드·지역/사진/FAQ/마무리·진행 순서도 글별로 작성합니다. 업무 카드와 같은 설명을 본문에서 두 번 출력하지 않습니다. 기존 글과 같은 구성 문구나 주요 문단이 반복되면 이전 내용을 유지하고 오류를 안내합니다. 직접 단어를 무작위 교체하지 말고 실제 사진·업무에 맞는 내용을 확인해 주세요. 기존 공개 글의 본문/제목은 운영자가 수정→기존 사진으로 자동 작성→확인 발행할 때 바뀌며 이전 공개 내용과 대표 URL은 보존합니다.

자동 작성은 사진 관찰과 본문 작성을 나눠 처리합니다. 사진에서 보이는 것과 업체가 실제로 작업한 사실은 다릅니다. 사진으로 확인되지 않은 촬영 지역·고장 원인·수리 결과·비용은 확정해서 쓰지 않고, 지역 유래·건물 연식 등은 출처가 확인된 지역 자료만 사용합니다. 완성 화면에서 사진과 내용을 대조하고, 필요한 부분은 ‘내용 수정이 필요한 경우’에서 고친 뒤 발행하세요. 작성 중에는 단계와 경과 시간이 표시됩니다.

접속: https://gongsa8282.xyz/admin/ 또는 메인 동네 안내 캐릭터의 오른쪽 바지 부분을 누릅니다. 기존 아이디·비밀번호로 로그인합니다.

## 업체·업종 목록과 삭제

업체는 **고객명 → 업체명 → 연락처 → 상태 → 관리** 순서의 촘촘한 목록입니다. 고객명 가나다순이며 미등록 고객은 업체명순으로 뒤에 표시합니다. 고객명/업체명/전화번호로 검색하고 한 페이지50개씩 이동할 수 있습니다. 업종도 가나다순 표로 표시하며 상위 업종·연결된 게시글 수를 확인할 수 있습니다.

각 행의 **삭제**를 누르면 대상과 처리 범위를 먼저 보여줍니다. 확인 체크 후 **삭제 보관함으로 이동**을 누르면 현재 목록에서 숨깁니다. 업체를 삭제하면 연결된 글의 공개도 중단하지만 글·사진·이전 내용·계약/배정 기록은 유지합니다. 삭제 보관함에서 **복원**하면 비활성 업체로 복원되므로 업체 수정에서 활성으로 바꿔야 다시 공개됩니다.

게시글 또는 활성 하위 업종이 연결된 업종은 삭제되지 않고 연결 수를 안내합니다. 하위 업종과 게시글 연결을 정리한 뒤 삭제할 수 있습니다. 상위 업종까지 삭제한 경우 상위를 먼저 복원해야 합니다. 삭제된 항목을 수정하려면 먼저 복원하세요. 이 기능은 영구 삭제가 아닙니다.

## 업체 등록

**업체 → 업체 등록**에서 고객명·업체명·소개·서비스 지역·전화번호를 입력합니다. 고객명은 글을 작성할 때 업체를 찾기 위한 내부 이름이며 공개하지 않습니다. 이름이 비슷한 업체도 고객명과 업체 번호로 구분합니다. 기존 업체는 수정 화면에서 고객명을 추가할 수 있습니다.

전화번호 확인 항목, 네이버플레이스 주소·등록명·주소·영업 안내, 실제 후기 등록은 유지합니다. 시험용 표시는 기본 해제입니다. 명시적으로 시험용으로 설정한 업체/글은 메인에서 제외됩니다.

## 글 작성과 발행

1. **사진으로 작성** → 고객 선택. 해당 업체명과 확인된 전화번호가 연결됩니다. 필요하면 해당 글의 전화번호를 따로 입력할 수 있습니다.
2. 전국 작업 지역과 제목에 쓸 지역명·대표 업무 키워드를 입력합니다. 제목은 자동 완성됩니다.
3. 사진을 선택하고 **사진으로 포스팅 자동 완성**을 누릅니다. 진행 상태·실제 경과 시간이 표시됩니다. 등록된 사진으로 다시 작성할 수도 있습니다.
4. 완성된 사진 설명·본문·지역 소개·상담 안내를 읽고 **확인하고 발행**을 누릅니다. 바로 메인·지역·업종·업체 화면에 표시됩니다. 내용 수정은 필요할 때 펼칩니다.

초안 저장·검수 요청·승인 단계와 작업자/배정·계약 메뉴는 없습니다. 계약 유무·기간·수량으로 발행을 막거나 수량을 차감하지 않습니다. 내부 작성 중 보관은 사진 처리·오류 복구를 위한 것으로, 확인 버튼을 누르기 전에는 공개되지 않습니다. 사진·자동 작성 버튼만 누른 상태로는 발행하지 않습니다.

발행 후 **수정하기**를 누르면 변경 중 글이 일시 비공개로 바뀝니다. 사진·내용을 변경한 뒤 다시 확인하고 발행합니다. 기존 주소·최초 발행일과 이전 공개 내용은 보존합니다. 과거 REVIEW/APPROVED 글은 ‘수정하고 발행하기’로 작성 화면에 돌아갈 수 있습니다. 기존 비공개 글을 일괄 발행하지 않습니다.

## 보호·운영

관리자만 발행할 수 있습니다. 기존 EDITOR의 접근 범위는 배정된 업체의 자기 글로 유지하며 권한을 자동으로 확장하지 않습니다. 인증·CSRF·최신 버전·중복 제목/본문/사진·높은 유사도·업체 활성 상태를 확인합니다. 발행 실패는 해당 저장/발행 요청 전체를 되돌리고 진행 안내에 오류와 확인 링크를 표시합니다.

관리 페이지·미공개 사진은 인증이 필요하고 no-store/noindex입니다. 계약·배정·과거 발행/수정 기록은 원본 보존용으로 남습니다. 고객명은 공개 데이터에서 제거합니다. 업종은 **업종 → 업종 추가**에서 이름만 입력하면 가나다순으로 반영됩니다.

## 고객별 게시글 목록·삭제·네이버 확인 (2026-11-18)

게시글 관리에서 고객명을 맨 앞에 두고 가나다순으로 정렬합니다. 한 페이지는 50건이며 순번은 현재 필터 목록 전체를 기준으로 이어집니다. #번호는 변경되지 않는 글 ID입니다. 고객명 검색 또는 고객 선택으로 해당 고객의 글만 보고, 상태와 네이버 확인 결과로 더 좁힐 수 있습니다.

- 개별 삭제: 행의 삭제 → 고객·업체·제목 확인 → 삭제 보관함으로 이동.
- 선택 삭제: 현재 페이지의 체크박스로 선택 → 선택한 글 삭제 → 확인. 상단 전체 선택은 현재 페이지에만 적용합니다.
- 고객 전체 삭제: 고객을 정확히 선택 → 이 고객 게시글 전체 삭제 → 전체 목록과 건수 확인. 현재 검색어·상태·페이지와 관계없이 **같은 고객명이 연결된 모든 업체**의 삭제되지 않은 글을 포함합니다. 동명이인은 별도 고객명으로 구분하고 확인 화면의 업체 목록을 읽어 주세요. 한 번에 최대 1,000건입니다.
- 삭제 보관함에서는 개별·선택 복원, 삭제 완료 안내에서는 이번에 삭제한 글 함께 복원을 제공합니다. 내용·사진·주소·이력은 보존합니다. 복원은 작성 중 상태이며 공개하려면 다시 확인하고 발행합니다.

네이버 1페이지 표시는 자동 순위 수집이 아닌 **관리자가 직접 확인한 기록**입니다. 발행된 실제 업체 글의 확인 결과 기록을 열고 표시된 읍·면·동+대표 업무 키워드로 네이버 통합검색 첫 번째 결과 페이지를 확인합니다. 해당 글의 공개 주소가 실제로 있는지 확인한 뒤 있음/찾지 못함/확인 실패, PC·모바일, 메모를 저장합니다. 보안문자·오류는 미노출로 단정하지 않고 확인 실패로 기록합니다. 날짜와 확인자를 서버에서 기록하며 공개 페이지에는 고객명·확인 메모를 표시하지 않습니다.

예: 인천 연수구 송도동 보일러누수 → 검색어 **송도동 보일러누수**. 지도·플레이스·다른 글이 보이거나 site: 검색에서만 보이는 것을 이 글의 첫 페이지 노출로 기록하지 않습니다. 글·검색어·주소가 변경되거나 기록 후 7일이 지나면 재확인이 필요합니다. 7일은 내부 관리 기준이며 네이버의 공식 기준이 아닙니다. 화면·시점에 따라 결과가 달라질 수 있으므로 날짜·기기를 함께 봅니다. 신규 글은 실제 확인 전까지 미확인입니다. 검색 준비 검사 통과·색인 등록은 1페이지 확인으로 계산하지 않습니다.
