# 관리자 사용 안내

접속: https://gongsa8282.xyz/admin/ 또는 메인 맨 아래 작은 빨간 핀. 기존 아이디·비밀번호로 로그인합니다.

## 업체 등록

**업체 → 업체 등록**에서 고객명·업체명·소개·서비스 지역·전화번호를 입력합니다. 고객명은 글을 작성할 때 업체를 찾기 위한 내부 이름이며 공개하지 않습니다. 이름이 비슷한 업체도 고객명과 업체 번호로 구분합니다. 기존 업체는 수정 화면에서 고객명을 추가할 수 있습니다.

전화번호 확인 항목, 네이버플레이스 주소·등록명·주소·영업 안내, 실제 후기 등록은 유지합니다. 시험용 표시는 기본 해제입니다. 명시적으로 시험용으로 설정한 업체/글은 메인에서 제외됩니다.

## 글 작성과 발행

1. **사진으로 작성** → 고객 선택. 해당 업체명과 확인된 전화번호가 연결됩니다. 필요하면 해당 글의 전화번호를 따로 입력할 수 있습니다.
2. 전국 작업 지역과 제목에 쓸 지역명·대표 업무 키워드를 입력합니다. 제목은 자동 완성됩니다.
3. 사진을 선택하고 **사진으로 포스팅 자동 완성**을 누릅니다. 진행 상태·실제 경과 시간이 표시됩니다. 등록된 사진으로 다시 작성할 수도 있습니다.
4. 완성된 사진 설명·본문·지역 소개·상담 안내를 읽고 **확인하고 발행**을 누릅니다. 바로 메인·지역·업종·업체 화면에 표시됩니다. 내용 수정은 필요할 때 펼칩니다.

초안 저장·검수 요청·승인 단계와 작업자/배정·계약 메뉴는 없습니다. 계약 유무·기간·수량으로 발행을 막거나 수량을 차감하지 않습니다. 내부 작성 중 보관은 사진 처리·오류 복구를 위한 것으로, 확인 버튼을 누르기 전에는 공개되지 않습니다. 사진·자동 작성 버튼만 누른 상태로는 발행하지 않습니다.

발행 후 **수정하기**를 누르면 변경 중 글이 일시 비공개로 바뀝니다. 사진·내용을 변경한 뒤 다시 확인하고 발행합니다. 기존 주소·최초 발행일과 이전 공개 내용은 보존합니다. 과거 REVIEW/APPROVED 글은 ‘수정하고 발행하기’로 작성 화면에 돌아갈 수 있습니다. 기존 비공개 글을 일괄 발행하지 않습니다.

## 보호·운영

관리자만 발행할 수 있습니다. 기존 EDITOR의 접근 범위는 배정된 업체의 자기 글로 유지하며 권한을 자동으로 확장하지 않습니다. 인증·CSRF·최신 버전·중복 제목/본문/사진·높은 유사도·업체 활성 상태를 확인합니다. 발행 실패는 해당 저장/발행 요청 전체를 되돌리고 진행 안내에 오류와 확인 링크를 표시합니다.

관리 페이지·미공개 사진은 인증이 필요하고 no-store/noindex입니다. 계약·배정·과거 발행/수정 기록은 원본 보존용으로 남습니다. 고객명은 공개 데이터에서 제거합니다. 업종은 **업종 → 업종 추가**에서 이름만 입력하면 가나다순으로 반영됩니다.
