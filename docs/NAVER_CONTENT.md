# 네이버 노출을 위한 작성과 확인

## 사업 기준

지역명+업무 키워드 검색에서 고객이 실제 포스팅 노출을 확인한 뒤 비용을 받는다. 약 50개는 대략적인 참고 목표다. 글 50개 발행, 크롤링 성공, 색인 수를 비용 청구가 가능한 실제 검색 노출로 대체하지 않는다. 자동 청구나 확정된 50건 결제 문턱은 구현하지 않는다.

2026-11-17 `gongsa8282.xyz`를 새 이웃핀 운영 Worker로 전환하고 네이버 소유 확인·사이트맵/RSS 제출을 완료했다. 네이버 robots.txt 수집과 113번 글의 수집 가능 판정, 첫 포스팅 수집 요청 접수를 확인했다. 운영 주소는 검색 수집을 허용하며, 시험 Worker는 noindex/nofollow와 robots 차단을 유지한다. 실제 검색 노출 건수를 확인한 상태는 아니다. 포털 기능 진척과 사업 목표 달성은 구분한다.

## 작성 방법

1. 관리 → **사진으로 작성**에서 업체·지역·업무 키워드를 입력한다. 제목은 두 입력값으로 즉시 완성된다.
2. 사진을 선택하고 **사진으로 포스팅 자동 완성**을 누른다. 기본 정보 저장, 사진 등록, 사진 설명·본문 생성이 이어진다. 별도의 본문 작성 영역이나 자동 작성 선택 체크박스는 없다.
3. 이미 등록한 사진이 있으면 사진을 새로 선택하지 않고 같은 버튼으로 작성할 수 있다. 실패 후에도 저장된 사진을 다시 올릴 필요가 없다.
4. 완성된 글은 사진과 함께 한 곳에서 확인한다. 내용 수정이 필요할 때만 접힌 편집란을 연다. 관리자가 확인하고 발행 버튼을 누르면 바로 공개한다.

사진 등록 전에는 본문 입력칸과 대기 안내문을 보이지 않는다. 대기 안내문 상태로는 확인 여부와 관계없이 발행할 수 없다. 생성 전 제목·본문과 입력 사진 ID를 비공개 기록에 보관하며, 실패·버전 충돌 시 기존 본문과 저장된 사진을 보존한다. 검색엔진이 실제 결과에 표시할 제목은 다르게 정할 수 있다.

## 굵은 글씨와 지역 정보

`**방충망 교체**`는 굵은 글씨, `## 상담 전 확인 사항`은 소제목으로 표시한다. 원문 HTML은 실행하지 않는다. 출처는 HTTPS 링크로 표시할 수 있으며 제공 본문 외부 링크에는 새 창과 noopener/noreferrer/ugc/nofollow를 적용한다. 플레이스 링크는 nofollow로 제공한다. [2026-11-18 공식 기준 점검](SEARCH_AUDIT_20261118.md)

지역 유래는 김포시 문화관광의 공식 지명 자료를 확인해 사우동·북변동·운양동의 짧은 요약을 제공한다. 김포 범위의 정확한 해당 이름에만 적용하며 다른 지역의 유래는 지어내지 않는다. 북변동처럼 행정동 목록과 다른 법정동 이름을 입력할 때는 선택 지역과 업체의 명시된 서비스 지역을 함께 확인한다.

지역 유래를 붙이는 것만으로 중복 문서 판정을 피하거나 검색에 노출된다고 볼 수 없다. 사진과 실제 작업 정보가 다른 고유한 포스팅을 작성하고, 날짜·작업 장소·원인·작업 결과·가격 등 확인되지 않은 사항은 추정하지 않는다. 촬영 장소와 서비스 가능 지역도 다르다. 자동 문구는 사람의 사실 확인을 대체하지 않는다.

## 자동 작성 연결과 한도

Cloudflare Workers AI의 `@cf/meta/llama-4-scout-17b-16e-instruct`를 사용한다. 서버가 해당 글에 연결된 비공개 R2 사진을 읽어 바이트로 전달하며 외부 임의 URL을 조회하지 않는다. 256KB 이하 커버를 우선 사용하고 큰 사진은 썸네일로 대체한다. 요청당 총 2MB 이하, 출력 3,200토큰으로 제한한다.

하루 전체 10회·글당 3회 시도를 DB에서 원자적으로 예약한다. 실패도 시도 수에 포함한다. AI 연결이 없는 개발 환경에서도 기존 직접 작성·사진 등록은 작동한다. Free 요금제에는 Cloudflare의 무료 할당이 있고 소진 시 요청이 실패한다. 이 기능은 유료 요금제로 자동 전환하지 않는다. 계정 자체를 유료로 바꾸면 제공업체의 초과 사용 요금 정책을 별도로 확인해야 한다.

## 실제 노출 확인 단계

운영 도메인 전환 및 네이버 사이트 소유 확인 → 검색 수집 허용과 sitemap/RSS 제출 → 수집·색인 상태 점검 → 목표 검색어에서 해당 URL 노출 확인 → 고객 확인 순서로 진행한다. 결과 기록에는 검색어, 포스팅 URL, 확인 시각, 화면 증빙과 고객 확인 내용을 남긴다. 같은 URL이 여러 검색어에서 발견되어도 별도 포스팅 여러 개로 세지 않는다. `site:` 결과만으로 목표 검색어 노출을 확정하지 않는다.

운영 도메인·소유 확인·수집 허용·사이트맵/RSS 제출을 완료했다. 네이버 화면에서 11:27:29(한국시간)에 수집된 robots 규칙과 `https://gongsa8282.xyz/post/113/`의 수집 가능 판정을 확인했다. 11:29:10에 동일 글의 첫 수집 요청을 접수했다. 이는 요청 접수이며 본문 수집·색인 완료를 뜻하지 않는다. 수집/색인 리포트와 목표 검색어 노출, 고객 확인·청구는 아직 완료하지 않았다. 현재 공개 글은 113·117번 2개이며 114/116번 초안을 임의로 공개하거나 확인 처리하지 않았다.

현재 노출 증빙 전용 화면·고객 확인·청구 기능은 미구현이다. 운영 기준과 필요 증빙을 먼저 위처럼 명시한 상태이며 임의 노출 수치나 고객 확인 기록을 만들지 않는다.

## 본문 보강과 정보 유지

본문 구성은 지역 소개와 확인한 출처, 업무별 상담 안내, 사진별 설명, 상담 준비/FAQ, 업체·네이버플레이스 정보입니다. 같은 구성의 블로그형 포스팅을 편집 결과/미리보기/공개 화면에서 표시합니다. 은평문화원·은평구 주민센터 자료를 확인해 응암동의 지명/백련산·매바위 소개를 추가했습니다. 전국의 미확인 유래는 만들지 않고 선택 지역과 작업 대상/방문 조건을 안내합니다.

업무별로 규격·설치 위치·틀/부품·반입 조건 등 상담에 필요한 사항을 구성하며 가격이나 실제 시공 완료는 추정하지 않습니다. 지역 유래는 작업 불량이나 건물 노후의 근거로 사용하지 않습니다. 사진을 재분석하지 않는 기존 본문 보강은 이전 문단을 보존해 기록하고 AI 일일 한도와 구분합니다.

## 관리 화면에서 준비 상태 확인

‘네이버 노출 준비’(`/admin/search-readiness/`)는 관리자 조회 전용이며 실제 업체의 글만 모아 표시한다. 업체·게시 상태로 필터하고 25개씩 이동한다. 제목과 실제 검색용 제목의 지역명+업무 접두부, 요약, 본문 작성/확인 여부, 활성 사진 수, 동일 제목/본문 해시·사진 재사용을 점검하고 지역 소개/FAQ/플레이스 구성 여부를 표시한다. 문장 유사도나 네이버 중복 판정을 대신하는 검사는 아니며 구성 유무나 글자 수를 노출 점수로 환산하지 않는다.

검색어 확인 링크는 입력한 지역명+업무로 네이버 검색 페이지를 열 뿐 결과를 수집하거나 자동으로 노출 확인 기록을 만들지 않는다. 운영용 URL은 canonical 설정을 기준으로 표시하고 시험 주소에서는 ‘예정’으로 구분한다. staging은 검색 제외 상태를 명시한다. 개발/운영 환경 문구는 현재 설정에 대한 안내이며 실제 도메인 연결·소유 확인·수집·검색 결과까지 자동 확인한 것이 아니다.

공개 글 수와 ‘실제 검색 노출 미확인’을 함께 표시한다. 고객 확인과 증빙·청구 기능은 여전히 미구현이며 약 50개를 강제 결제 조건으로 만들지 않는다. 시험 주소의 검색 제외를 유지하고 운영 주소만 명시적으로 수집을 허용한다. 이전 시험 관리 링크는 운영으로 이동하며 이전 폼 저장을 차단한다.

## 판매용 상담 페이지와 고유 본문

개별 포스팅 화면은 상단 전화 안내 이미지와 HTML 전화 링크, 세부 상담 항목, 지역/사진 본문, 진행 순서와 FAQ, 업체·플레이스로 구성합니다. 고객 후기는 실제 원문과 게시 가능 여부를 확인해 업체에 등록한 경우만 표시합니다. 기존 공개 글 본문은 자동으로 다시 쓰지 않습니다.

새 자동 작성은 사진 관찰 후 별도의 본문 집필을 수행합니다. 사진에 보이는 특징을 구체적인 상담 주제·준비 항목·FAQ와 연결하고 해당 본문에서 검색 설명을 작성합니다. 발행 전 지역명과 업무 키워드를 제거한 같은 업체의 본문 유사도를 검사하며, 단순 지역명 치환 글은 보강을 요청합니다. 이 내부 검사와 정확 해시/사진 중복 검사는 네이버 판정이 아닙니다. 공통 업체 정보·연락처·일반 절차는 같은 사실을 유지합니다. [상담 페이지 운영](CONSULTATION_PAGES.md)
