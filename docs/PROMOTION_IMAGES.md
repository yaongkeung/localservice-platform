# 전화 상담 홍보 이미지

2026-11-19. `src/promotion-graphic.js`는 검증된 페이지 전화번호/업체 번호, 제목 지역명·업무, 업종별 AI 작업자 이미지를 합성한다. 기존 말풍선을 대체한다. 추가 입력이나 매번 이미지 생성 API 호출 없이 글 수정에 맞춰 전화·문구가 바뀐다. 실제 촬영 장소·시공 성과를 추정하지 않는다.

`public/media/service-workers-a.jpg`와 `service-workers-b.jpg`는 내장 이미지 생성 도구로 새로 제작한 각 4×2 이미지 묶음이다. 배관, 창호, 에어컨, 전기, 운반, 컴퓨터, 청소, 상담과 자동차, 건설, 간판, 원단, 배달, 돌봄, 열쇠, 인쇄의 장면을 제공한다. 명칭·전화번호는 생성 모델에 맡기지 않고 코드에서 정확한 등록 값으로 합성한다. 가족 선택은 업무 키워드 기준이고 알 수 없는 업종은 상담 장면으로 대체한다. 현장 사진은 그대로 보존하며 AI 광고 이미지를 실제 사진 목록/작업 실적/사진 중복 확인에 섞지 않는다.

업체 상담 시간에 24시간/24시가 명시된 경우에만 `24시 상담`을 표시하며 부정·예약 제한 문구는 제외한다. 연중무휴만으로 24시간을 추정하지 않는다. 등록되지 않은 무료견적·A/S·자격·즉시 출동 문구는 붙이지 않는다. 사진과 텍스트는 한 SVG 이미지로 표시하고 외부 출처·추적 스크립트·새 API 비밀키를 사용하지 않는다. RSS에서는 호환되지 않는 장식 SVG를 제외하고 원본 사진·전체 본문과 상담 링크를 보존한다.

공통 광고의 차이를 검색 품질·고유 현장 정보의 차이로 취급하지 않는다. 새 글은 실제 사진과 확인된 업무 내용이 필요하다. 생성 입력 문구 원문은 작업 결과의 `dongnepin-promotion-image-prompts-20261119.txt`에 보관했다.
