# 발행·수정·검색 구조

## 전국 작업 지역

시·도 → 시·군·구 → 읍·면·동을 선택하고 제목에 쓸 지역명을 입력합니다. 번호로 나뉜 동은 같은 시군구 안에서 합쳐 표시하고 기존 행정코드와 URL을 보존합니다. 읍·면은 유지합니다. 선택한 지역 범위를 벗어나는 제목 지역명은 거부합니다. [출처·원자료 편제](REGION_DATA.md)

## 확인 후 즉시 발행

현행은 **고객 선택 → 글·사진 작성 → 확인하고 발행**입니다. 고객 선택 값은 업체 ID로 연결하며 고객명은 관리자 전용입니다. 본문·사진·업체 정보는 하나의 포스팅에 이어집니다. 계약·초안 저장·검수 요청·승인 단계를 작성자에게 요구하지 않습니다. 자동 사진/본문 작성은 발행 전 작성 중 내용만 변경합니다.

관리자가 확인 버튼을 누르면 내용 저장과 DRAFT→PUBLISHED를 하나의 원자적 batch로 처리합니다. 실패하면 그 요청의 내용·상태 이력이 함께 되돌아갑니다. 인증·CSRF·최신 버전·업체 활성·제목/본문/사진 중복과 높은 본문 유사도 검사는 유지합니다. 계약 기간·수량·유무로 제한하거나 수량을 차감하지 않습니다. 이전 REVIEW/APPROVED 상태는 이력 호환용이며 화면에서는 작성 중으로 묶습니다.

발행하면 메인·지역·업종·업체 화면, 사이트맵·RSS에 표시됩니다. 시험용·비활성·미래 글과 미공개 사진은 제외합니다. 기존 비공개 글을 이번 migration으로 일괄 발행하지 않습니다.

## 수정

관리자가 **수정하기**를 누르면 변경 중 글이 비공개로 전환됩니다. 전환 직전 공개 내용·관계·발행일·사진 메타데이터는 post_snapshots에 보관합니다. 수정 후 다시 확인하고 발행하면 같은 숫자 URL과 최초 발행일을 유지합니다. 과거 계약 연결/수량과 감사 기록은 재작성하지 않습니다. 기존 EDITOR 접근 범위는 배정된 업체의 자기 글로 유지하며 새 권한을 부여하지 않습니다.

## 검색과 노출

서버 HTML, 제목/설명/canonical/OG, Breadcrumb/Article, 사이트맵·RSS를 자동 제공합니다. sitemap은 공개·기한 도래 글과 실제 글이 있는 업체·지역·업종을 포함하고 관리/쿼리/빈 페이지를 제외합니다. RSS는 최근 변경 공개 글 최대 50개와 같은 숫자 URL guid를 사용합니다. robots는 관리자 경로를 제외하고 공개 사진의 접근을 허용합니다.

검색 제목은 지역명+업무 키워드로 시작합니다. 사진 관찰 후 구체적인 업무 내용·상담 준비·FAQ를 작성하고 출처가 확인된 지역 소개와 굵은 업무 표기를 유지합니다. 지역명만 바꾸거나 문장만 무작위 변경하여 일괄 발행하지 않습니다. 실제 후기·작업 결과가 확인되지 않은 경우 생성하지 않습니다.

네이버 소유 확인·사이트맵/RSS 등록·수집 허용·첫 글 수집 요청은 완료했습니다. 발행 수·수집·색인·실제 검색결과 노출·고객 확인은 다르며 노출/순위나 비용 지불을 보장하지 않습니다. 운영의 실제 검색 노출 축적과 고객 확인·비용 지불 검증이 남아 있습니다. 이전 시험 주소는 검색 제외·읽기 전용 보관입니다.
