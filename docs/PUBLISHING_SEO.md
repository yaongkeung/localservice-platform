# 전국 지역·공개 글 수정·검색 노출 자동화

## 전국 지역 글쓰기

글쓰기에서 ‘전국 지역에서 선택’ → 시·도 → 시·군·구 → 읍·면·동을 고릅니다. 상위 지역 전체 범위도 선택할 수 있습니다. 기존 글은 ‘기존 지역 유지’를 기본으로 하며 기존 숫자 ID와 지역 URL을 바꾸지 않습니다. 예전 수원시처럼 읍면동 코드가 없는 집계 지역도 임의의 동에 배정하지 않고 그대로 보존합니다.

목록은 기존 원자료 기준 16개 시도·256개 시군구 단위·3,559개 읍면동을 사용합니다. 기준일·출처·편제는 [REGION_DATA.md](REGION_DATA.md)를 따르며 현행 행정구역의 법적 판단 자료가 아닙니다. 게시글 저장 시 선택한 경로의 지역만 코드 기준으로 등록합니다. 전체 지역 이름으로 글이나 빈 게시판을 미리 생성하지 않습니다. 이미 등록된 코드는 재사용하고 시도/시군구/읍면동 조합이 다르면 저장을 거부합니다.

새 지역 slug는 상위 경로/코드 기반이며 기존 `seoul/mapo` 등의 주소는 보존합니다. 공개 데이터에는 공개 글의 지역과 그 상위 지역만 포함합니다. 아직 글이 없거나 공개 해제로 글이 사라진 새 지역 페이지는 404입니다. 업종의 빈 게시판은 기존 탐색을 위해 noindex로 표시합니다. 지역 선택 스크립트는 늦은 응답을 무시하고 상위 변경 때 하위를 비웁니다. JavaScript를 끄면 기존 지역 유지와 서버에 이미 표시된 선택만 가능하며 새 하위 목록을 불러오지 못합니다.

## 공개 해제·수정·재검수

관리자가 공개 글에서 ‘공개 해제하고 수정’을 누르면 PUBLISHED → DRAFT가 됩니다. 공개 글·사진·메인/지역/업종/업체 목록과 사이트맵/RSS에서 빠집니다. 서버 응답은 캐시하지 않지만 외부 검색엔진·공유 서비스가 보관한 내용의 삭제까지 즉시 처리하는 기능은 아닙니다.

공개 해제 직전 제목·요약·본문·관계 ID·게시일과 사진 메타데이터를 post_snapshots에 저장합니다. 관리 화면의 ‘이전 공개 내용 보기’는 최근 20개 기록의 제목/본문을 읽기 전용으로 보여주고 보관 시각은 한국시간으로 표시합니다. DB에는 전체 기록이 남습니다. 자동 원상복구나 원본 이미지 파일의 버전 보관 기능은 아닙니다. 현재 사진 제외는 비파괴 방식이므로 파일은 유지됩니다.

초안을 수정한 후 기존 DRAFT → REVIEW → APPROVED → PUBLISHED 흐름을 다시 거칩니다. EDITOR는 배정된 자기 글의 초안만 수정·검수 요청하며 공개 해제/승인/공개는 관리자 전용입니다. 원본 글은 같은 숫자 ID URL과 최초 게시일을 유지합니다. 공개한 이력이 있으면 최초 업체와 계약을 바꿀 수 없고, 재공개 시 최초 계약 사용 수량을 다시 차감하지 않습니다. 공개 해제도 기존 사용 수량을 환급하지 않습니다. 이전 계약이 종료되어도 해당 글의 수정 재공개는 가능하며 업체는 활성 상태여야 합니다. 실제 업체가 계약 없이 공개한 샘플 글을 재사용하는 것은 허용하지 않습니다.

## 자동 메타데이터와 피드

- `/sitemap.xml`: 공개 글, 글이 있는 업체·지역(상위 포함)·업종(상위 포함), 메인만 포함합니다. 미공개/미래/비활성 업체의 글, 빈 지역·업종, 관리자/쿼리 URL은 제외합니다. 게시글 lastmod만 실제 updated_at/게시일에서 만듭니다.
- `/rss.xml`: 최근 변경된 공개 글 최대 50개, 제목·요약·최초 게시일·대표 썸네일을 제공합니다. guid는 숫자 ID 영구 URL이므로 수정 재공개를 새 글로 중복 발행하지 않습니다. 같은 URL의 내용이 바뀔 때 구독기에서 어떻게 표시할지는 각 구독기의 동작에 따릅니다.
- `/robots.txt`: 관리자 경로를 제외하고 사이트맵 주소를 안내합니다. 공개 업로드 사진은 검색기가 접근할 수 있도록 uploads 전체를 막지 않습니다. 미공개 사진은 서버 권한 검사로 감춥니다.
- 공개 HTML: title/description/canonical/OG, RSS 발견 링크, 페이지의 보이는 탐색 경로에 대응하는 BreadcrumbList를 제공합니다. 게시글은 Article의 dateModified/작성 업체/실제 공개 이미지 URL을 포함하고, 대표 사진이 있으면 해당 사진으로 OG 이미지를 만듭니다. 사진 없는 글에 다른 글 사진을 배정하지 않습니다.

URL은 고정된 시험 도메인 `https://gongsa8282.xyz`를 사용하고 요청 Host를 복사하지 않습니다. XML의 텍스트/속성 및 JSON-LD를 이스케이프합니다. 공개 해제 반영을 위해 HTML·피드·사이트맵은 no-store입니다. 폼 입력과 관리 화면은 기존 CSRF/권한/버전 검사와 no-store/noindex를 유지합니다.

설계 참고: [Google 사이트맵 안내](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap), [BreadcrumbList 안내](https://developers.google.com/search/docs/appearance/structured-data/breadcrumb), [RSS 2.0 명세](https://www.rssboard.org/rss-specification). 코드 생성·자동 갱신을 구현한 것이며 검색엔진 등록·실제 색인/노출·리치 결과를 보장하거나 확인한 것은 아닙니다.

## 검증·남은 작업

38개 테스트는 전국의 모든 읍면동 계층, 잘못된 조합, 경로 중복 등록, 공개 해제 후 모든 노출 경로 제외, 보관 기록/권한, 최초 게시일/계약 유지, XML 이스케이프/HEAD, 메타데이터/대표 사진과 이전 DB 업그레이드를 포함합니다. 로컬 브라우저에서 강내면 선택·글 수정·재검수·재공개·계약 1건 유지와 모바일 가로 넘침 없음을 확인했습니다.

실제 Cloudflare D1/R2 연결, workerd 실행/부하, 백업/복구, 배포/검색엔진 검증은 아직입니다. 계정 비밀번호 변경·재발급·로컬 복구는 OPERATIONS.md를 따릅니다. 스키마는 0004 migration으로 기존 공개 이력을 보존합니다. 기본 샘플 초기화는 published_once를 명시하여 재공개 때 신규 글로 집계하지 않게 합니다.

현행 계정 복구·로컬 실제 엔진·백업/복원·배포 준비의 검증 범위는 [OPERATIONS.md](OPERATIONS.md)를 참고하세요. 원격 Cloudflare 검증은 아직 수행하지 않았습니다.
